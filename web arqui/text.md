Brief explanations of each component (diagram 1)
Web Architecture

1. Frontend
   The frontend is the part of the website that users can see and use.
2. Buttons, Forms and Recipe List
   Buttons let users click and do things. Forms let users enter recipe information. The recipe list shows all saved recipes.
3. HTTP Requests and HTTP Responses
   This is how the frontend and backend communicate. The frontend sends requests, and the backend sends answers back.
4. Backend
   The backend works behind the scenes. It receives requests and handles the recipe information.
5. GET, POST, PUT and DELETE
   These are used to tell the backend what to do:
   GET – View a recipe.
   POST – Add a new recipe.
   PUT – Edit a recipe.
   DELETE – Remove a recipe.
6. Database Queries and Query Results
   The backend sends requests to the database. The database sends back the information or confirms that something is done.
7. Database
   The database is where all the recipes are saved so they can be found later.
8. Recipes, Ingredients and Instructions
   This is the information saved in the database, such as recipe names, ingredients and cooking steps.
